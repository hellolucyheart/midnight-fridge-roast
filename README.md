A tiny deterministic program that writes one line of text to `/output/entry.txt`: a roast of a smart fridge that refuses to open after midnight. No network, no clock, no randomness — every run writes exactly the same line, and the program reads the file back to verify the bytes it wrote.

> My fridge locks at midnight like the leftovers filed a restraining order — I'm hungry, not a burglar.

## Run it

```sh
python3 main.py
```
